Introducción a HTML

¿Qué es HTML?

HTML (Lenguaje de Marcado de Hipertexto) es el código que se utiliza para estructurar y desplegar una página web y sus contenidos.

Es un conjunto de etiquetas incluidas en archivos de texto que definen la estructura de un documento web y sus vínculos con otros documentos.

Analogía simple

HTML es como el esqueleto de una página web. Define la estructura básica, mientras que CSS (hojas de estilo) sería como la piel y ropa que le da apariencia, y JavaScript sería como los músculos que le dan movimiento.

Objetivos de aprendizaje

  • Comprender la estructura básica de una página HTML
  • Aprender a utilizar las etiquetas HTML más comunes
  • Ser capaz de crear una página web básica desde cero
  • Entender cómo agregar imágenes, enlaces y tablas
  • Conocer buenas prácticas de desarrollo web
